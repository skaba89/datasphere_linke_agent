## Gaps concurrentiels (ce qui nous différencie)

### 1. Hermes — Agent IA autonome (UNIQUE)
Aucun concurrent n'a un agent IA qui s'exécute automatiquement pour générer du contenu, analyser les prospects, vérifier les tokens et produire un résumé. C'est notre différenciateur principal.

### 2. CRM intégré avec scoring (UNIQUE)
Taplio et Buffer n'ont pas de CRM. Notre CRM avec scoring, déduplication, séquences et funnel de conversion est unique dans cette catégorie de prix.

### 3. Multi-IA avec fallback (UNIQUE)
5 providers IA avec fallback chain automatique. Si Gemini est down, GLM prend le relais. Aucun concurrent n'offre cette résilience.

### 4. MCP Server (UNIQUE)
Compatible Claude Desktop, Cursor et tout client MCP. Les utilisateurs peuvent intégrer DataSphere dans leur workflow IA existant.

### 5. Prix
- Taplio Pro : 39€/mois → DataSphere Pro : 29€/mois (26% moins cher)
- Taplio Teams : 199€+ → DataSphere Business : 79€ (60% moins cher)
- Plan gratuit avec 3 posts/jour (Taplio n'en a pas)

## Positionnement

**DataSphere 360** se positionne comme la plateforme **"LinkedIn IA tout-en-un"** pour les créateurs de contenu B2B, freelances et petites agences qui veulent :

1. **Générer** du contenu avec l'IA (multi-provider)
2. **Automatiser** la publication et le suivi (Hermes)
3. **Gérer** leur pipeline commercial (CRM + scoring)
4. **Mesurer** leur performance (analytics + revenue)

**Pricing sweet spot** : 29€ (Pro) — entre AuthoredUp (15€) et Taplio (39€), avec plus de fonctionnalités que les deux.
